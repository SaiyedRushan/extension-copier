How it works

Chrome keeps every profile separate, so there's no built-in way to move extensions between them. Most people end up searching the store for each one again. This does the searching for you.

  1. Pick the two profiles

    The app reads your Chrome profiles from your Mac and lists the extensions in each. Anything the other profile already has is marked, so you don't add it twice.

  2. Tick the extensions you want

    Everything starts ticked. Untick what you don't need in the new profile.

  3. Click Add to Chrome on each page

    Chrome opens each extension's store page in the right profile, one at a time or all at once as tabs. The app notices each install within about 10 seconds and opens the next. Close it halfway and it offers to finish the list next time you open it.

  4. Copy their settings too, if you want

    With Chrome closed, the app can copy what each extension has saved, like your Dark Reader site list or your Tampermonkey scripts. It keeps a backup of anything it replaces, and there's an Undo button.

Why you still click Add to Chrome

Chrome only installs extensions from the Chrome Web Store, and only when you say so. The one way around that is editing Chrome's signed settings file, which is what malware does. Chrome notices and turns the extensions off.

Going through the store also means your extensions keep updating themselves, the same as if you'd added them by hand.

What it can't copy

  • Extensions that aren't on the Chrome Web Store, like ones you loaded from a folder in Developer mode. The app lists them, but there's no store page to add them from.
  • Site access you gave an extension, and whether it's allowed in Incognito. Chrome keeps those in its signed settings file.
  • Data some extensions keep in storage Chrome shares between all sites. The app marks these as "Only partly", and you may need to sign in to them again.

It doesn't send anything anywhere

There's no account and no analytics, and the app doesn't connect to the internet. It reads Chrome's files on your Mac. The only thing it writes into Chrome's folder is a settings copy you start yourself.

All the code is on GitHub if you'd like to check.

Built for Mac

It's a small native app built with Tauri, for macOS 12 or later. It works with Google Chrome. Brave, Edge and Arc store extensions the same way, so adding them would be a small change if someone wants to take it on.

Questions

Is it free?

Yes. It's open source under the MIT license, and there's nothing to pay for.

Doesn't Chrome sync already do this?

Only between profiles signed in to the same Google account with sync turned on. This is for profiles on different accounts, like work and personal, or profiles with no account at all.

Do I need to be signed in to Chrome?

No. Adding extensions from the Chrome Web Store works in any profile, signed in or not.

What happens to the profile I copy from?

Nothing. The app only reads it.

Can I undo a settings copy?

Yes. Before copying, the app moves whatever the other profile had for those extensions into a backup. Undo puts it back. You can undo from the screen you copied on, or later from your history in the app.

Does it work on Windows or Linux?

Not yet. Most of the app doesn't care which system it's on, so a Windows version is mostly a matter of finding Chrome's folder there. Open an issue if you'd like it, or if you want to help build it.

Is this made by Google?

No. It's an independent open source project and isn't affiliated with Google.

Help other people find it

Extension Copier is a small open source project. If it saved you some time, a star on GitHub is the easiest way to help. It makes the project easier for other people to find.

Found a bug or want something added? Open an issue. Pull requests are welcome, and the README explains how to run it on your Mac.
